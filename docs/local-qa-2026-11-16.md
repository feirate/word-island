# 词遇岛 0.6.2 本地体验记录

2026-11-16。本轮从孩子的使用路径检查现有本地程序，并直接修复可复现的问题。

## 环境与范围

- 实际运行地址：`http://127.0.0.1:4173/`，项目静态文件服务，无学习业务后端。
- 本机 Chrome + 已有 Playwright，使用独立浏览器上下文与临时用户，未操作孩子的真实浏览器记录。
- 页面、localStorage、IndexedDB、Web Locks、音频解码、Service Worker 均执行实际代码；旧存档使用仓库固定样本，录音使用 Chrome 测试音源。
- 重点体验：新手引导、听辨与拼写、跟读、倒序完成任务、领奖回家、书架、伙伴、用户管理、导入导出、双窗口以及离线。
- 窗口尺寸：375×667、390×844、768×1024、844×390、1024×768；低高度窗口只用于布局探查。
- 沿用本项目静态 ES 模块与现有存档格式，未安装依赖、增加服务器、提交、推送或部署。

## 发现与修复

以下问题均先在页面或测试中复现，再保留原行为断言复测。

| 问题 | 原表现 | 修复后 |
| --- | --- | --- |
| 拼写重试丢失输入 | 答错或点提示后，输入框被重建并清空 | 同一道题保留字母与光标；错答可直接修改，正确后可用 Enter 继续；草稿不跨用户或题目 |
| 输入法 Enter 误提交 | 确认组合输入候选字也增加错误尝试 | 组合输入期间不提交，不产生错误记录 |
| 自由练习锁住每日教材 | 只随便练一个词就创建每日任务；随后换单元仍被旧计划锁住 | 自由练习只更新词级统计与复习时间；明确进入每日任务时才固定计划 |
| 倒序学习重复指路 | 短句、拼写已做完，最后完成听辨仍推荐再做拼写 | 按尚未完成的任务推荐；全部完成后直接指向宝箱 |
| 手机领奖后看不到家 | 弹窗关闭后仍停在页面底部，小屋在屏幕上方 | 回小屋、去营地、打开图鉴时让场景回到视野；进入学习时仍定位任务区 |
| 双窗口覆盖进度 | 同一用户一页答听辨、另一页答拼写，后写入覆盖先前成绩；不同单元朗读标记也会互相覆盖 | 存储锁内读取最新进度后应用本次操作，朗读标记合并保存；其他窗口收到更新后刷新显示 |
| 删除与保存交错时无选择器 | 删除后排队保存被拒绝，但旧页面没有重新弹出用户选择 | 保存结束后强制回到选择器；不会复活已删除用户的进度或录音 |
| 损坏音频覆盖可用声音 | 无法解码的文件也显示导入成功，以后该词一直无法播放 | 导入前在本地解码检查，坏文件不覆盖旧声音；旧库中的坏文件播放失败时回退内置示范并提示 |

双窗口导入前备份也在同一存储锁内读取最新存档；存储损坏需要恢复时，先保留原文再写新记录，备份失败不会覆盖原数据。

## 仍需实际试用确认

- iPhone / iPad Safari 真机的触摸、软键盘、麦克风、音量与主屏幕离线体验。本轮窗口模拟和测试音源不能代替真机检查。
- 双窗口互斥已在支持 Web Locks 的本机 Chrome 验证；不支持 Web Locks 的旧浏览器仅有单页面操作队列，跨窗口互斥尚未验证。
- 进度 JSON 不包含用户列表、引导设置、示范音频、个人录音，以及当天尚未领取线索的独立朗读勾选；新设备需要重新确认该次朗读。家长入口和 README 已说明。
- 孩子能否听清、理解提示、愿意开口并连续回来，需要孩子自己的实际反馈，本轮不据浏览器检查推断学习效果。

本轮按 `$ub-mode` 先复现、再做最小兼容修改，分开每日计划与自由练习，用现有锁保护本地数据，并通过真实页面、存储、解码及离线回归验证。
