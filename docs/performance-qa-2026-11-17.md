# 0.7 终端性能优化验收

本轮继续使用 GitHub Pages，无学习业务后端，不变更存档格式或学习规则。开发任务见 [任务清单](performance-tasks-2026-11-17.md)。

## 实际变化

| 项目 | 结果与口径 |
|---|---|
| 学习代码 | 入口与 Three.js 拆分，首批学习 JS 约 40 KB gzip；全部打包 JS 约 210 KB gzip。均为本地同算法压缩估算，不是公网测时 |
| 12 个三维模型 | 原始 8,281,540 → 发布 5,954,916 字节；本地 gzip 3,526,382 → 2,871,805 字节，减少约 18.6% |
| 几何数量 | 总三角形 283,552 → 281,796。主要收益来自量化和去重，不宣称大幅减面；建筑保持原三角形，避免墙面光照改变 |
| 手机渲染 | Chrome 手机仿真：原活跃/静置均约 60fps；现活跃约 30fps，静置 5 秒后约 12fps，触摸、镜头和庆祝恢复 |
| 绘制尺寸 | 手机 DPR 为 1、阴影 512，并限制总像素；后台、视口外与减少动态效果偏好仍生效 |
| 图鉴资源 | 页面活动 XHR 峰值从 8 降为 1；最多保留当前和最近一只模型，过期结果忽略并释放 |
| 安装与音频 | 安装只准备学习程序，不下载 206 条音频或整套模型；当前单元和到期复习音频按需缓存 |
| 更新复用 | 真实 SW 从 0.7.0 更新到测试版本 0.7.1，未变化资源零重复下载；包含哈希代码、CSS、模型和音频 |
| 完整离线 | 测试故意缺少一条音频时不会宣称完整就绪；修复后仅补该文件，整包代码和资源实际断网读取成功 |

原始 GLB、Blender 母版和素材制作脚本保留，精简仅发生在构建产物内。没有添加浏览器端几何解码器或远程素材依赖。节点名、extras、父子语义与动画通道均作构建校验，完成十二模型正面、侧面、背面、三分之四视角及角色动作极值的前后对照。

## 行为验证

- 最终 `npm run build` 成功，`node --test --test-reporter=spec tests/*.test.js` 共 164 项通过，零失败；`git diff --check` 通过。
- 单元测试覆盖：学习、用户/录音隔离、旧存档迁移、奖励规则、下载无进度超时、后台缓存不阻塞网络、缓存升级、单元音频范围、准备任务去重和有界并发、失败重试、渲染预算、启动分离与构建语义。
- 发布包核心学习：真实三维物件点击、听辨与拼写重试、测试音源录音和 IndexedDB、奖励与演示隔离、进度导出/导入、离线重载、390/768 尺寸。
- 故障恢复：Three.js 模块失败不阻断学习；解除故障后重试可恢复；用户离开后迟到的模块不创建无用视图；图鉴 A→B→A 的旧解析不会提前隐藏当前加载提示。
- 用户与伙伴：创建/选择/删除、三个用户上限、个人录音隔离、八位灰色预览与解锁原色、全部入住热点、离线动物、引导与气泡。
- 手机原有修复：持续下载不会因总计 30 秒误杀；缓存写入人为阻塞时完整网络响应仍先到；无 WebGL 可继续学习，context lost 有恢复提示，安装/激活等待有明确期限。
- 单元缓存状态：旧用户/旧单元的迟到成功不改变当前状态；失败不永久锁死同一单元，短暂冷却后可继续，恢复网络可立即重新准备。
- 最小核心离线：仅打开选人页并等安装完成即可断网新建用户、进入听辨和输入拼写。构建将用户录音迁移使用的轻量 storage 动态代理一并纳入核心；三维仍保持延迟加载。

新增或更新的可重复检查包括 `browser-startup.cjs`、`browser-startup-recovery.cjs`、`browser-render-budget.cjs`、`browser-album-budget.cjs`、`browser-cache-policy.cjs`、`browser-cache-upgrade.cjs`、`browser-model-comparison.cjs` 和既有业务回归工具。测试只使用隔离上下文和合成用户/麦克风，不读取孩子的实际浏览器数据。

## 边界

- 实际 iPhone 的耗电、发热、内存和 Safari/微信体验尚需本版真机确认；Chrome 手机模拟不等同真机。
- 页面取消 XHR 不保证 Service Worker 的后台完整缓存同步中止；已经进入解析的旧模型也不能强制终止，会在结束后忽略/销毁。实测有 worker 时服务器侧旧传输峰值为 6，不能宣称所有 HTTP 传输绝对只有一个。
- 0.6.4 升级到本版时，精简过的模型内容确实改变，需下载新模型；未变音频可校验复用。0.7.0→测试 0.7.1 的未变内容复用另有真实升级验证。
- 完整离线准备持续有文件进度时可超过 30 秒；无新进度 30 秒或总用时达到 5 分钟会结束本轮界面等待，已成功文件保留。它是文件级恢复，不是 HTTP 字节断点续传。

遵循 ub-mode：用旧行为失败固定下载、缓存、快速切换与异步时序，再做可兼容的小步修复。模型按 scene-to-three 的三维视觉与动作验收流程检查；构建期间不改原始模型母版。开发工具固定在 package-lock.json，运行端仍为纯静态网页。
