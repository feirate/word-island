# 八位伙伴的三维资产

本轮按用户要求创作可爱的立体小兔、松鼠、小猫、小狗、刺猬、乌龟、浣熊和狐狸。小兔团团复用现有已确认模型；七只新角色沿用暖色微缩玩具的材质、胖圆身体、大头、小爪、亮眼和柔和口鼻。所有角色具有侧面与背面体积，图鉴大预览与小屋使用相同 GLB。

## 身份与造型

| ID | 名字 | 保留的辨识特征 | 主色与主动设计 |
| --- | --- | --- | --- |
| bunny | 团团 | 既有长耳、奶白身形、绿色小围巾 | 完整复用已有模型，未重建 |
| squirrel | 栗栗 | 抱松果、蓬松卷尾、小尖耳 | 栗棕与奶油色，连续融合的卷尾 |
| cat | 米米 | 三角耳、额头三条纹、细长弯尾 | 奶油灰，薄荷色围巾；不是橘皮角色 |
| dog | 豆豆 | 垂耳、圆口鼻、短而上翘的尾巴 | 浅金与奶油色，小棕围巾 |
| hedgehog | 刺刺 | 奶油脸、背部刺壳、短小圆钝刺 | 暖棕色，40 根低面数短刺 |
| turtle | 慢慢 | 低矮四脚、圆龟壳、壳片纹路、小尾巴 | 草绿与浅黄绿，实际壳面上的立体细纹 |
| raccoon | 圈圈 | 圆耳、眼罩、灰黑相间的环尾 | 温暖灰色；尾部为连续网格上的材质条带 |
| fox | 橙橙 | 尖耳、奶油脸颊、大尾与白尾尖 | 浅奶橙与蓝色围巾；没有芽芽的探险背包与深色靴子 |

名字和材质是本轮主动设计；动物种类、可爱方向和真实立体形态来自用户要求。角色不是动物生物学还原。尾巴、隐藏侧背面和坐姿按微缩玩具的整体一致性设计。

## 制作与结构

使用本机既有 Blender 4.5.15 LTS，构建脚本为 `tools/build_companions.py`，复用 `tools/build_world.py` 的连续曲面、材质和基本几何工具。未安装或下载依赖、模型、贴图或声线。

七只新伙伴分别提供 `assets/models/companions/<id>.blend` 可编辑母版和 `<id>.glb` 网页运行资产。Blender Z-up、正面 -Y 转换为 glTF Y-up、正面 +Z，静止脚底均为 y=0。角色根有 `role=companion` 与 `assetId`；头、呼吸躯干与尾巴有独立控制组。模型不携带互动 ID，点击、灰色状态、学习奖励和对话由程序控制。

每只模型包含一段首尾闭合的约四秒 idle：躯干轻微呼吸、头部轻点和转向；有尾巴者还带轻摆。脚部不跟随呼吸缩放，保留地面接触。头部所有五官、口鼻和耳朵随头部控制组联动。没有制作自然行走、战斗、口型或骨骼步态。

同一动画控制组下的静态同材质网格会合并，避免每个小部件各自增加绘制调用。环尾材质在同一连续网格上分区，未把几段不连续的圆柱当作整条尾巴。

## 实际验收与修正

- `design/check-companion-models.cjs` 先复现七份模型不存在，再验证身份、真实网格、头部层级、真实头部动画通道、动画片段、文件预算和可编辑母版；最终七只通过。
- `scene-to-three/scripts/validate_glb.py` 分别检查七份新 GLB。
- `design/render-companions.cjs` 在本机 Chrome 使用项目本地 Three.js r180 与 GLTFLoader，真实加载八只角色；检查脚底 y=0、头部子节点和推进 idle 后四元数确实变化，未出现页面错误。
- 实际查看正面、侧面、背面、三分之四角和 idle 极值，截图在 `design/screenshots/companions/`，运行数据在其中的 `runtime-check.json`。
- 松鼠初稿的卷尾有不自然的截面折痕，改为连续融合的蓬松体；腹部初稿像薄浮片，改为嵌入躯干的有厚度体积；猫额纹改为沿宿主曲面取样；乌龟壳纹改为沿真实椭球壳面；浣熊条纹尾的段间接缝改为连续环面；刺猬去掉每根小刺的重复倒角，GLB 从约 820 KB 降到 433 KB，保留短钝刺的辨识度。
- 图鉴八张 `<id>-portrait.png` 是实际 GLB 的 256×256 三分之四角截图，不是概念生图或替代模型的图片。模型缩放后等待画布实际刷新再拍摄，避免快速 GPU 缩放截图伪影。

总览见 `design/screenshots/companions-lineup.png`；侧背面检查图见 `design/screenshots/companions/side-back-review.png`。这轮是本机浏览器的结构、视觉与动画检查，不等同于 iPhone / iPad 真机性能或孩子最终审美认可。

## 重建与复验

```sh
/path/to/Blender --background --python tools/build_companions.py -- --output assets/models/companions
node design/check-companion-models.cjs
COMPANION_ASSETS=bunny,squirrel,cat,dog,hedgehog,turtle,raccoon,fox node design/render-companions.cjs
```

第二条和第三条检查不用于发布，不增加网站运行依赖。第三条需要开发机已有 Playwright、Chrome 与本地静态服务；其地址默认为 `http://127.0.0.1:4173`。
